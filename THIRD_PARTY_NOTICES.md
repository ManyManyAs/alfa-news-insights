# Сторонние компоненты, модели и данные

Здесь перечислено всё стороннее, что использует «Бизнес-радар»: библиотеки с точными версиями, языковые модели, системные компоненты и данные. Версии библиотек закреплены в `backend/requirements.lock` и `backend/uv.lock`, так что сборка воспроизводима. Если версия здесь расходится с lock-файлом, верен lock-файл.

## Языковые модели

Используются только модели из Приложения 3 кейса, через эндпоинт организаторов (OpenAI-совместимый API). Клиент отказывает в вызове, если id модели не входит в список разрешённых (`config/models.yaml`). Ключ хранится только на сервере (секреты GitHub Actions, `.env`), в браузер и в репозиторий не попадает.

| Ключ | id модели | Для чего используется |
|---|---|---|
| gemma | `google/gemma-4-26b-a4b-it` | Классификация новостей, реранк ленты, арбитраж дублей |
| deepseek | `deepseek/deepseek-v4.1-flash` | Разбор события для всех клиентов; персональный разбор и его правка (автор); офлайн-судья |
| glm | `z-ai/glm-5.3-flash` | Критик разбора (другая модель, чем автор); запасной автор |
| qwen | `qwen/qwen3.6-35b-a3b` | План агента, чат по разбору |
| kimi | `moonshotai/kimi-k2.6` | Конспект длинных документов банка |
| qwen_vl | `qwen/qwen3-vl-30b-a3b-instruct` | Распознавание страниц PDF-аналитики банка (OCR) |

Роутинг выбран по бенчмарку на задачах сервиса: `docs/llm/BENCHMARK.md`, решение описано в `docs/QUALITY.md`.

Локальных моделей по умолчанию нет. Опционально можно включить эмбеддинги: модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (Apache-2.0) через `fastembed`. Без них поиск по базе знаний банка идёт по BM25 со стеммером собственной реализации.

## Frontend

Фронтенд написан без фреймворков и сборки: `frontend/*.js` и `*.css`. Карта влияния, радар и графики — собственный SVG. Сторонних JS-библиотек, CDN и веб-шрифтов нет: страница работает без доступа в интернет и проходит строгую CSP (`script-src 'self'`).

## Данные

- **Данные кейса** (`data/case/`): компании, физлица и связи, продукты, платежи. Предоставлены организаторами хакатона и используются только для решения кейса.
- **Аналитика Альфа-Банка** (`data/knowledge/`): тезисы и макропрогнозы, извлечённые из материалов, предоставленных организаторами. У каждого тезиса указаны документ, дата и страница.
- **Новости** (`config/sources.yaml`): RSS-ленты и официальные сайты — Банк России, Правительство, Kremlin.ru, Интерфакс, ТАСС, РИА Новости, ПРАЙМ, РБК, Коммерсантъ, Ведомости, Лента.ру, Российская газета, Банки.ру.
  - Сервис хранит заголовок, короткий фрагмент и ссылку, а пользователю показывает ссылку на первоисточник.
  - Права на тексты принадлежат изданиям.
- **Демо-набор новостей** (`data/sample/news_seed.jsonl`) и **синтетические компании** (`data/sample/`) созданы командой для тестов и офлайн-оценки.
- **Размеченные данные для оценки** (`data/eval/`) созданы командой.
