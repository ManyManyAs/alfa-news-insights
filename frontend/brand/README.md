# Логотип

Положите сюда официальный логотип Альфа-Банка из брендбука организаторов — файл `logo.svg` (квадратный, без поля вокруг).
Сервис подхватит его сам: знак в шапке и на экране входа заменится логотипом. Если файла нет, показывается
нейтральный знак Бизнес-радара. Рисовать чужой товарный знак вручную не стали — только официальный файл.
