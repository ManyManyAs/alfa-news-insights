# Логотип Альфа-Банка

Официальные файлы со страницы «Логотипы и брендинг» alfabank.ru (передали организаторы хакатона, использование разрешено),
переведены из PDF в SVG без изменений формы:
- `alfa-mark-red.svg` — основная версия знака (литера «А» с фундаментом), позитив;
- `alfa-mark-red-bg.svg` — знак на красном фоне;
- `alfa-bank-long-red.svg` — длинная версия «Альфа Банк».

Как применено в интерфейсе (по брендбуку «Визуальный образ банка», v.02):
- знак без тени и подложки, на белом — красный (позитив), на чёрном — белый (негатив);
- охранное поле вокруг знака не занято другими элементами;
- фирменный красный #EF3124, чёрный, серые #505759 и #D9D9D6; «фундамент» (красная черта) — акцент у заголовков разделов.
