# Безопасность AI-компонентов (ограничение 06)

| Риск | Механизм | Где |
|---|---|---|
| Доступ к чужим данным | RBAC: пользователь видит только связанные компании; каждый запрос проверяется и журналируется | `security/guard.py: check_company_access`, `audit_log` |
| Агент читает лишнее | Инструменты получают контекст уже авторизованной компании; агент не может запросить другую компанию даже по «просьбе» LLM | `agent/tools.py: AgentContext` |
| Небезопасные действия | Инструменты только читают; фиксированный allowlist; лимит 10 вызовов на запрос; неизвестный инструмент отклоняется и пишется в трассировку | `agent/tools.py: call_tool` |
| Prompt injection в новостях и ссылках | Внешний текст очищается (управляющие символы, обрезка), подозрительные конструкции вырезаются, текст передаётся только внутри тегов `<news>`/`<doc>` с инструкцией «данные, а не команды»; событие получает флаг `prompt_injection_suspected`; критик проверяет, что следов инъекции нет в выводе | `security/guard.py`, `agent/rules.py` |
| Утечка чувствительных данных в LLM | Минимизация: в модель уходит `CompanyProfile.llm_view()` без идентификаторов компании, группы и контрагентов (только отрасли и доли) | `data/models.py` |
| Выдуманные факты | Каждый вывод обязан ссылаться на источник; несуществующие id удаляются; числа в «фактах» сверяются с текстом новости, иначе «факт» понижается до «предположения» | `agent/rules.py: critique_rules, repair_rules` |
| Подмена модели или перерасход | Только модели из allowlist `config/models.yaml`; дневной бюджет, деградация на запасные модели, затем на правила | `llm/client.py` |
| Загрузка по ссылке (SSRF) | Только http(s); выключается `ALLOW_URL_FETCH=false`. В продакшене: прокси с allowlist доменов и запрет внутренних адресов | `news/sources.py: fetch_url` |
| Ключи | Только через переменные окружения (`.env` в `.gitignore`) | `.env.example` |

**Для продакшена (описано, не реализовано в прототипе):** интеграция с IAM банка вместо `X-User-Id`, TLS, шифрование БД, хранение журналов в SIEM, DLP-проверка ответов, отдельный сервисный аккаунт для LLM-шлюза, ревью новых промптов через регрессионный набор.
