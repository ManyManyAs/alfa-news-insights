## Жёсткие правила

1. **Секреты никогда не попадают в код, коммиты, логи и сообщения.** Ключ LLM (`LLM_API_KEY`), доступ к серверу и всё прочее лежит только в GitHub Secrets. Не печатайте их и не просите вставить в чат. Правило организаторов: «Не публикуйте ключ в открытых репозиториях и чатах и не размещайте его в браузерном коде приложения». Если с ключом проблема, организаторам передают название ключа и текст ошибки, но не сам ключ.
2. **На сервер не заходите напрямую.** Деплой — только через GitHub Actions (`deploy.yml` запускается при push в `main`).
3. **Работа идёт через ветку и PR:** ветка → PR → зелёный CI → squash-merge → деплой → проверка. В `main` напрямую не пушить.
4. **CI блокирует падение офлайн-метрик больше чем на 0,05** (`backend/scripts/quality_gate.py`, база `docs/quality/baseline.json`). Базу обновляют только при сознательном изменении разметки или модели, в том же PR, с объяснением.
5. **Язык — русский:** интерфейс, документация, комментарии, сообщения коммитов. Пользователь (владелец проекта) общается по-русски, не программист, отчёты ему нужны короткие и по делу.
6. **Честность цифр важнее эффектности.** Суммы в рублях считает детерминированный калькулятор (`app/agent/scenario.py`), а не модель. Если эффект не оценивается честно, показывается «заметного влияния нет». Важность не завышается.
7. **Технических идентификаторов в клиентском интерфейсе быть не должно** (`graph:in:71`, `profile:CL_PRODUCT_…`, `OKVED`, имена полей). Для этого есть `app/agent/humanize.py`. Раздел «Для команды банка» и вкладка «Как получен вывод» — исключение: там трассировка нужна по критериям.

## Команды

```bash
cd backend
pip install -r requirements.lock          # Python 3.12
python -m pytest -q                       # тесты (mock-режим LLM, синтетика data/sample)
ruff check .                              # линтер (лимит строки 140)
# офлайн-метрики так же, как в CI:
DATA_SOURCE_DIR=../data/sample DB_PATH=/tmp/eval.db LLM_MODE=mock USE_SNAPSHOT=false \
  python scripts/evaluate.py --insights --json /tmp/q.json && python scripts/quality_gate.py /tmp/q.json ../docs/quality/baseline.json
# локальный сервер на данных кейса и сохранённых ответах моделей (без ключа):
DATA_SOURCE_DIR=../data/case LLM_MODE=replay python -m uvicorn app.main:app --port 8000
```
