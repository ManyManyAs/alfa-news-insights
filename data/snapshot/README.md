# Снапшот результатов LLM

Ключ к моделям организаторов перестаёт работать после приёма решений, а жюри проверяет репозиторий.
Поэтому результаты прогона в режиме `live` (события, инсайты, трассировки агента, ответы моделей)
сохраняются сюда командой `make snapshot` (`scripts/manage.py snapshot-export`) и автоматически
подгружаются при первом запуске.

Режим `LLM_MODE=auto` (по умолчанию): есть ключ — модели вызываются вживую; ключа нет — `replay`:
сохранённые ответы моделей отдаются из снапшота, а для новых запросов (например, своей новости)
сервис честно переходит на детерминированный режим (в карточке видно «генерация: rules»).

Снапшот привязан к набору данных (`manifest.json → data_fingerprint`) и не применяется к другим данным.
